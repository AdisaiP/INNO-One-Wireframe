## INNO.One usage rules

- Use one illustration family across the product.
- Illustration is decorative/supporting content, not the primary information source.
- Do not place decorative illustration in dense operational screens such as Remote Session, Ticket Detail, Device Detail, permission matrices or workflow canvases.
- Hero illustration: roughly 160–280 px depending on context.
- Empty-state illustration: roughly 120–180 px.
- Prefer transparent SVG and the INNO.One primary accent.
- Use empty alt text for purely decorative artwork; meaningful state illustrations require accessible text in the surrounding component.
