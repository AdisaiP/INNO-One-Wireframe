# INNO.One

The active production implementation lives in production/.

## Repository layout

- production/ - canonical application source, services, packages, infrastructure, tests, and production documentation.
- docs/ - architecture, contracts, UX/UI references, and roadmap documents.
- archive/ - historical prototype and development/QA records kept only for reference.

Historical step-by-step handoff files and generated visual QA outputs are intentionally excluded from the active project surface.
