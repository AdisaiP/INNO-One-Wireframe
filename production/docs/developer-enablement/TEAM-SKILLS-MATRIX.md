# Team Skills Matrix

No single engineer must master every area, but every module owner must understand platform boundaries.

## Backend engineer

Core: C#, ASP.NET Core, EF Core, PostgreSQL, REST/API design, OIDC/Keycloak fundamentals, modular architecture, unit/integration testing.

Must understand permission/scope, schema ownership, audit/events, and cross-module integration patterns.

## Frontend engineer

Core: React, TypeScript, TanStack React Query, React Router, REST integration, accessibility, design systems, OIDC fundamentals.

Must understand module manifest, permission-aware UI, surface ownership, and required UX states.

## Full-stack module owner

Must understand module boundaries, permission/scope, audit, events/contracts, database ownership, frontend-to-API flow, testing, and CI expectations.

## Platform / DevOps engineer

Docker, PostgreSQL operations, Keycloak, GitHub Actions, Linux, reverse proxy/TLS, secrets/configuration, monitoring/readiness.

## UX/UI engineer

INNO.One frozen design system, accessibility, page patterns, interaction feedback, responsive states, table/list density, and surface ownership.

## Shared expectation

Architecture must live in contracts and automated tests, not only in senior engineers' memory.
