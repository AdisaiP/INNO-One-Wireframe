# INNO.One Keycloak Login Concepts

Static preview only. These files are intentionally not wired into the active Keycloak realm yet.

Open `index.html` and choose one of the five directions:

1. Corporate Clean
2. Modern Workspace
3. Security & Trust
4. Operations Command
5. Friendly Enterprise

The concepts reuse the current INNO.One blue/white/ink visual language and existing Product illustrations from `apps/web-portal/public/illustrations`.

After one direction is approved, convert that concept into a proper Keycloak theme (`theme.properties`, FreeMarker templates, resources and realm configuration) instead of deploying these preview HTML files directly.
